# Roadmap (post-MVP, explicitly NOT in this build)

- **v0.2 — Capture:** WhatsApp/email forwarding + paste-from-share, file uploads
  with attachment summarization, intake from images.
- **v0.3 — Money:** quotes/invoices, per-order profitability, currency conversion
  display ( conversion never invents agreed amounts).
- **v0.4 — Together:** team workspaces, roles, client portal (read-only order
  status), activity feeds.
- **v0.5 — Time:** calendar sync, deadline reminders, recurring orders.
- **Later:** subscriptions/billing, mobile apps, multi-provider AI (Anthropic,
  Gemini) behind the same adapter interface, offline-first PWA.

Each item needs its own PRD slice and security review (especially integrations
and portals) before entering the plan.
